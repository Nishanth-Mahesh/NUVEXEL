# NUVEXEL Digital Solutions Website

## Open it
1. Extract the ZIP.
2. In VS Code: File > Open Folder > `nuvexel-website`.
3. Right-click `index.html` > Open with Live Server (or just double-click it).

## Edit details
All contact details and social links are in the `CONFIG` block at the top of `script.js`.
- Add LinkedIn, Facebook, X, YouTube links: paste the URL between the quotes. Icons are already on the page; empty ones appear faded and inactive.
- Email is a placeholder (`hello@nuvexel.com`). Change it in `CONFIG.email`.

## Replace the logo
Overwrite `assets/logo.png` (square works best) and `assets/favicon.png`. Keep the same file names.

## Diamond Ridge Constructions
Featured as the live client in the Work section of `index.html` (search "Diamond Ridge"). The other three cards are labelled "Concept".

## Images
Photos load from Unsplash. If one fails, a neutral grey block shows instead. To go fully offline, download images into `assets/` and change the `src` values.
